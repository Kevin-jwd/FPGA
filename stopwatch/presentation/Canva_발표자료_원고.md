## 02 · 개요

### 프로젝트 개요

**목표**  
FPGA에서 시간을 계수하고, 버튼으로 시계와 스톱워치의 동작 상태를 제어한다.

**구현 환경**  
Basys 3 보드 / Verilog HDL / Vivado

**주요 기능**

- 시계 모드: 분·초 표시
- 스톱워치 모드: 초기화, 시작, 정지 및 재시작
- 4자리 FND로 시간 표시, LED로 상태 및 계수 정보 출력
- 버튼 입력 동기화 및 디바운싱

발표자 메모: 현재 소스의 기능 구성과 설계 의도를 설명하는 페이지다. 시뮬레이션이나 실기 검증 완료를 뜻하지 않는다. 표시 의도는 시계 MM.SS, 스톱워치 SS.CC이며 CC는 1/100초 단위다.

## 04 · 구현 내용

### FSM과 버튼 제어

[기존 FSM 이미지 삽입 영역]

| 입력 | 상태 전환 |
| --- | --- |
| 왼쪽 버튼 | STOP_WATCH 진입 및 스톱워치 값 초기화 |
| 오른쪽 버튼 | CLOCK 복귀 |
| 위쪽 버튼 | CLOCK 이외의 상태에서 START 진입 |
| 아래쪽 버튼 | START에서 STOP으로 전환 |
| 리셋 | CLOCK 복귀 및 시간 카운터 초기화 |

제작 메모: 기존 `stopwatch_fsm.drawio.png`의 교체 가능한 삽입 영역을 확보한다. 표는 이미지 오른쪽 또는 아래에 배치한다. 이미지의 상태·전이 내용은 삽입 전 현재 코드와 대조한다.

발표자 메모: 실제 상태 전환 코드를 기준으로 정리했다. STOP에서는 스톱워치 계수를 멈추고, 위쪽 버튼으로 다시 START에 진입한다. IDLE은 파라미터와 LED 표시 분기만 있으며 진입 로직은 없다. 5초 후 IDLE 전환을 구현 기능으로 소개하지 않는다. 동시 입력의 우선순위는 왼쪽, 오른쪽, 위쪽, 아래쪽 순이다.

## 05 · 구현 내용 / 핵심 코드 1

### 1ms tick 생성

```verilog
parameter INPUT_FREQ = 100_000_000;
parameter TICK_FREQ  = 1_000;
parameter TICK_CNT   = INPUT_FREQ / TICK_FREQ;

// always 블록 내부 발췌
if (r_cnt == TICK_CNT - 1) begin
  r_cnt <= 0;
  tick  <= 1;
end else begin
  r_cnt <= r_cnt + 1;
  tick  <= 0;
end
```

**핵심 설명**

- 100MHz 입력 클럭의 100,000주기를 계수한다.
- 1ms마다 입력 클럭 한 주기 폭의 tick을 출력한다.
- 시간 계수와 FND 자릿수 선택의 기준으로 사용한다.

발표자 메모: `tick_generator.v`의 파라미터와 always 블록 일부를 발췌했다. 독립 실행용 전체 모듈은 아니다. tick은 50% 듀티의 1kHz 사각파가 아니라 1ms 간격의 펄스다.

## 06 · 구현 내용 / 핵심 코드 2

### 버튼 입력에 따른 상태 전환

```verilog
if (clean_btn[0] && !r_prev_btn[0]) begin
  r_mode = STOP_WATCH;
end else if (clean_btn[1] && !r_prev_btn[1]) begin
  r_mode = CLOCK;
end else if (clean_btn[2] && !r_prev_btn[2]) begin
  r_mode = (r_mode != CLOCK) ? START : CLOCK;
end else if (clean_btn[3] && !r_prev_btn[3]) begin
  r_mode = (r_mode == START) ? STOP : r_mode;
end
r_prev_btn <= clean_btn;
```

**핵심 설명**

- 디바운서는 2단 플립플롭으로 버튼 입력을 동기화한다.
- 약 10ms 동안 입력 변화가 유지되면 버튼 상태를 갱신한다.
- 이전 입력과 현재 입력을 비교해 눌림 시점에 상태를 전환한다.

발표자 메모: `main_controller.v`의 상태 전환 부분을 그대로 발췌했다. r_prev_btn 비교는 tick 상승 에지에서 수행한다. 위 설명의 동기화와 디바운싱은 별도 `btn_debounce10ms.v`에 구현되어 있다. 코드의 blocking 대입은 원본을 보존한 것으로, 권장 작성 예시로 제시하는 것은 아니다.

## 07 · 구현 내용 / 핵심 코드 3

### 표시 데이터 선택과 FND 구동

```verilog
// main_controller.v
assign seg_data =
  (r_mode == CLOCK)
    ? (r_min_cnt * 100 + r_sec_cnt)
    : (r_stopwatch_sec_cnt * 100
       + r_stopwatch_ms_cnt / 10);

// fnd_controller.v
assign d1    = in_data % 10;
assign d10   = (in_data / 10) % 10;
assign d100  = (in_data / 100) % 10;
assign d1000 = (in_data / 1000) % 10;
```

**핵심 설명**

- 시계는 분·초, 스톱워치는 초·1/100초 표시 데이터를 구성한다.
- 표시 값을 천·백·십·일의 자리로 분리한다.
- 1ms마다 선택 자릿수를 바꾸고, an과 seg를 LOW 활성으로 구동한다.

발표자 메모: 서로 다른 두 모듈에서 발췌한 코드다. 위 코드는 표시 형식에 대한 설명이며 스톱워치의 시간 정확도를 검증한 결과가 아니다. 현재 스톱워치 계수부에는 동일 레지스터의 중복 nonblocking 대입 때문에 경계값 초기화가 덮어써질 가능성이 있으므로, 정확한 계수 성능이나 검증 성공을 주장하지 않는다.

### 동작 시연

[동작 동영상 삽입 영역]

**시연 순서**

1. 리셋 후 시계 모드 확인
