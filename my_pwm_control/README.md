# My PWM Control

Basys 3 보드에서 버튼으로 PWM 듀티비를 조절하고, 스위치로 모터 방향 제어 신호를 출력하는 Verilog 프로젝트입니다. FND에는 듀티비와 방향 상태를 표시합니다.

## 개발 환경 및 동작

- Vivado 2020.2 / Basys 3 (Artix-7, `xc7a35tcpg236-1`)
- 100MHz 입력 클럭을 10카운트로 나누어 10MHz PWM 생성
- 듀티비: 0~90%, 10% 단위 조절, 초기값 및 리셋값 50%
- 버튼 입력에 약 10ms 디바운싱 및 상승 에지 검출 적용
- FND: 오른쪽 세 자리에 듀티비 표시 (예: `050` = 50%), 왼쪽에 방향 문자 표시
- 방향 문자는 1초마다 점등/소등 전환 (전체 점멸 주기 2초)

## 조작 및 출력

| 입력 | 기능 |
| --- | --- |
| 위 버튼 `btn[0]` | 듀티비 10% 증가, 최대 90% |
| 아래 버튼 `btn[1]` | 듀티비 10% 감소, 최소 0% |
| 가운데 버튼 `btn[2]` | 듀티비 0%로 설정 |
| `reset` (SW15) | 듀티비 50% 및 내부 상태 초기화 |
| `sw[1:0] = 10` | 방향 신호 `10`, FND에 `F` 표시 |
| `sw[1:0] = 01` | 방향 신호 `01`, FND에 `b` 표시 |
| `sw[1:0] = 00` 또는 `11` | 해당 방향 신호 출력, FND에 `S` 표시 |

| 출력 | 연결 |
| --- | --- |
| `pwm_out` | JA1, PWM 출력 |
| `in1_in2[0]`, `in1_in2[1]` | JA2, JA3, 스위치 값 전달 |
| `os_out` | JB7, 오실로스코프 측정용 PWM 출력 |
| `pwm_out_led` | LD0, PWM과 동일한 신호 |

## 주요 파일

소스 위치: `my_pwm_control.srcs/sources_1/imports/Downloads/`

- `top.v`: 최상위 모듈 및 신호 연결
- `pwm_duty_control.v`: 듀티비 조절 및 PWM 생성
- `btn_debounce10ms.v`: 버튼 디바운싱
- `tick_generator.v`: FND 자리 전환용 1kHz tick 생성
- `fnd_controller.v`: 듀티비 숫자 및 방향 문자 표시

Vivado에서 `my_pwm_control.xpr`을 열고 최상위 모듈 `top`과 XDC 연결을 확인한 뒤 합성 → 구현 → 비트스트림 생성 → 보드 다운로드를 진행합니다.
